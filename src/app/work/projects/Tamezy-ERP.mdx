## Overview

Tamezy ERP is a production web application built for Tamezy (Bahrain) to help small and medium businesses across the GCC region manage their sales, purchasing, inventory, and accounting in one place. The platform combines a modern Angular 17+ frontend with a Node.js / Express.js backend, PostgreSQL, and Prisma ORM, and is designed around GCC VAT compliance and audit-ready bookkeeping.

## Key Features

- **5 Core Modules**: Sales, Purchases, Inventory, Accounting, and Admin Settings in a single platform.
- **Quote-to-Cash & Purchasing**: 8+ document types (Quotations, Invoices, Delivery Notes, Receipts, Credit/Debit Notes, Bills) with automated line-item totals and real-time inventory adjustments.
- **GCC VAT Compliance Engine**: 10% VAT, zero-rated and exempt items, and TRN validation.
- **Double-Entry Bookkeeping**: Audit-ready accounting with Chart of Accounts and Journal Vouchers.
- **Multi-Currency & Multi-Unit Inventory**: Multi-currency support, multi-unit stock tracking, and low-stock reorder alerts.
- **Security**: JWT authentication and Role-Based Access Control (RBAC).

## Technologies Used

- **Frontend**: Angular 17+ (Standalone Components, Signals), RxJS / BehaviorSubjects, custom responsive SCSS design system
- **Backend**: Node.js and Express.js REST APIs
- **Database**: PostgreSQL with Prisma ORM
- **Security**: JWT authentication, Role-Based Access Control

## Challenges and Learnings

Modelling accounting rules correctly was the core challenge: every sales and purchase document had to post balanced double-entry journals, adjust inventory in real time, and apply the right VAT treatment per line item. Keeping the UI responsive across large document lists led to a custom SCSS design system, skeleton loaders, and reactive state synchronization using RxJS BehaviorSubjects.

## Outcome

Tamezy ERP gives GCC SMEs a VAT-compliant, audit-ready system for running day-to-day operations, from quotation through invoicing, payment, and reporting.
